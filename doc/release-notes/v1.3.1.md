# Resin v1.3.1

## Fixes

- The Platform status code rule editor now treats an empty end code as a single status code. Entering `429` alone matches exactly `429`; filling the end code still creates an inclusive range such as `500-599`.
- Single-code rules are rendered compactly as `429` instead of `429 ~ 429`.

## Upgrade Notes

- No database changes. Drop-in upgrade from v1.3.0.
- HTTP forward and reverse proxy traffic can observe status codes; CONNECT and SOCKS5 tunnels cannot.
